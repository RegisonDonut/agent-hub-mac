# AgentHub 1.11.0 Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish a verified AgentHub 1.11.0 macOS release containing the complete TOTP manager, current work dashboard fixes, and a self-contained Sub2API runtime, then update the team Artifact page.

**Architecture:** The release build remains a universal Swift app bundle. The bundle carries a generated release manifest that binds the package to an exact Git commit and enumerates its required executables and offline runtime components. Release verification operates on the final ZIP after extraction, and a Docker smoke test starts the bundled Sub2API/PostgreSQL/Redis images in an isolated project before distribution.

**Tech Stack:** Swift 5.9, SwiftUI, zsh, Docker Compose, GitHub Releases, Donut Artifact HTML.
